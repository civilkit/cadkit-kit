The ten fonts above are the curated list of the Text tool (`apps/cad/public/fonts/fonts.json`). Each file is unmodified and

that uses one stores only its id and checksum and fetches the file again; fonts a user adds are embedded in the document and
are the user's responsibility. No other font is shipped.
