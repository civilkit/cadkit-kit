- front moves along +Z, top along +Y, right along +X; a face offset goes along the face's OUTWARD normal (negative = into the body).
- { origin, normal } with a normal along a world axis is an ordinary offset plane; any other normal adds helper points and a three-point plane (7 features at most): fine for one-off tilted sketches, prefer rotate: { axis: 'x', angle } for a tilt about an axis.
- rotate turns the plane about the axis LINE, the plane passes through it; only world axes through the origin and straight edges are accepted.
- FRAME of { origin, normal, xdir }: the sketch origin is `origin`, sketch x (u) = xdir projected perpendicular to the normal, sketch y (v) = normal x u. Example: normal [1,0,0] with xdir [0,0,1] gives u = +Z and v = X x Z = -Y. Without xdir and with an axis-aligned normal the plane is the standard one (front / top / right frame below, a negative normal is flipped); without xdir and an oblique normal, u = normal x [1,0,0] (normal x [0,1,0] when the normal is nearly X). When a sketch lands in the wrong place, give xdir: it removes the guesswork.
- Standard frames (sketch x, sketch y, normal): front = X, Y, +Z; top = X, -Z, +Y; right = -Z, Y, +X. A point [u, v] on a plane offset by d is world = origin + u*x + v*y + d*normal.
