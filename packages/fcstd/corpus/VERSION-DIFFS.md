## Reading

- Dump level: all 84 models (and 79 variants) were built with FreeCAD 1.1.4 (build 20260928) and 1.1.3 (build 20260725) and re-opened. No
  numeric difference above 1e-6 relative and no structural difference (objects, properties, enumeration lists, sketch geometry and
  constraints, shape counts) was found. For the importer, 1.1.3 and 1.1.4 files need no separate handling.
- File level: the zip members are identical. `Document.xml` differs in: the `ProgramVersion` attribute (`1.1R20260928` vs `1.1R20260725`),
  the object `id` counters, the string hasher table and `Uuid` values (random per document), and the hash tag inside mapped element names
  (`shadow=";#14:1;:G0;XTR;:Hf96:8,F.Face6"` vs `:H513:8`), which is a per-session hash and not a model difference. The few geometry lines
  that differ are last-digit noise in coordinates (e.g. `StartY="0.0000000000000007"` vs `0.0`).
- During development the same comparison flagged the arcs of hyperbola/parabola in `13_sketch_conics`; that was an unconstrained sketch
  whose conics drift between solver runs (not a version difference). The model now blocks them (`Block` constraints) and the runs agree.
